# Правила стрелок (все типы схем)

Все стрелки ортогональные со скруглением (стиль в [styles.md](styles.md)).

1. **Вниз по цепочке** — строго вертикально, центр к центру (выход снизу по центру → вход сверху по центру).
2. **От ромба в ветки** — выход из **боковой** вершины (лево / право), не из низа. Горизонталь, затем вниз к ветке. Подпись ветки — **на вертикали после поворота**, не на горизонтали у ромба.
3. **С боковой ветки в центр** — вниз из низа блока, горизонталь под ним, без пересечения блоков.
4. **Слияние веток** — горизонталь **под низом** источника, затем к цели; не через середину блоков. Шина не режет соседние колонки.
5. **Петля ↺** — вправо по рельсу → вверх к уровню над головой цикла → в центр сверху.
6. **Длинный обход** — по левому (~34 px от края) или правому (~26 px от края) рельсу колонки.
7. **Между статусами / колонками** — прямая в зазоре или по внешнему каналу.
8. Из одной вершины ромба — не больше одной стрелки.
9. Стрелки разных связей не сливаются: у каждой свой уровень и свои точки выхода / входа.
