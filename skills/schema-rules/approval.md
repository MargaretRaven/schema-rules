# БП согласования документа (тип 1.7)

Шаблон БП **вне стадий CRM**: согласование договора, спецификации, счёта, инвестиционного комитета. Запуск — при создании элемента, из живой ленты, кнопкой.

## Признаки

- Широкий 2D-холст (координаты ± тысячи px), не узкая колонка.
- Старт подписан по триггеру: «при создании элемента» / «из живой ленты».
- N-way развилки (тип договора → 3+ параллельных пути).
- Блоки утверждения / рецензирования с подписанными исходами «Согласовано / На доработку / Отклонено / Утверждено» и **петлёй на доработку**.
- Много «Сохранить поля и комментарии…», глобальные константы — тексты полные.
- Параллельные ветки — рядом, а не друг под другом.
- **Нет** легенды цветов слева, как у 1.2a.

## Палитра (своя — не смешивать с 1.1 и 1.2)

| Цвет | Смысл |
|------|-------|
| Жёлтый | сохранить поля / системные действия |
| Синий | служебные / информационные блоки |
| Зелёный | согласовано / задание человеку / рецензия |
| Красный | отклонено / на доработку (отказные пути) |
| Ромб | условие / исход согласования |
